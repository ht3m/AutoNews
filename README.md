# 全球与中国新闻周报

纯静态网站，无需安装依赖或运行构建命令。Netlify 发布目录为仓库根目录 `.`，生产分支为 `main`。

- `index.html`：最新一期完整正文。
- `archive.html`：期刊目录，缺期明确标注。
- `issues/YYYY-MM-DD.html`：按覆盖周的周日日期保存的固定链接。
- `assets/`：本地数据图，说明和来源见正文图注。
- `content/`：本期编辑内容与信源记录，便于后续更新。

## 后续每周更新

按北京时间的上一个完整自然周检索、核验新闻。先为新一期建立固定链接，更新最新首页与历史目录，保留所有旧期。检查日期、原始链接、图片说明、事实与分析区分，以及移动端排版后提交。推送到 main 会由已连接的 Netlify 项目自动发布。

每周四北京时间 09:00 是外部编制任务的计划；这个静态仓库本身不执行新闻检索、不包含定时生成服务。连接 Netlify 只提供推送后的部署，不会自行生成下一期。
